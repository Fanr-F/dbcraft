# DBCraft 详细自测清单

| 项目 | 内容 |
|---|---|
| 目的 | 每次提交/发版前，用统一清单覆盖用户可见功能、近期回归点和边界条件 |
| 适用版本 | M1（2026-11-18 工作区，含 W-20261118-01～13） |
| 关联文档 | `prd/PROJECT_MASTER.md` §5、`prd/FEATURE_MATRIX.md` |
| 状态标记 | `[自动]` 已有脚本覆盖；`[半自动]` 脚本覆盖主路径，UI 仍需点一遍；`[手工]` 只能人工验收 |
| 记录方式 | 用 §16 模板记录日期、构建/工作区、环境、失败项与截图 |

> 原则：**没在真实 Electron 里点过，不写“通过”**。自动化通过只代表主路径没有回归，不代表 UI/交互已经人工验收。

| EDIT-08 | 手工 | 大小写、引号标识符、CTE、子查询别名 | 插入项跟随输入大小写；引号内可补全；CTE/别名列可展开 |

| EDIT-11 | 手工 | Tab / Shift+Tab / Ctrl+M | 弹层打开时 Tab 接受候选；否则插入空格/按行缩进；Ctrl+M 切换 Tab 焦点模式 |
| EDIT-12 | 自动 | 多语句 `SELECT 1; SELECT 2;` | 多结果页签 + 消息面板；遇错停止；逐条结果 |
| EDIT-12b | 自动 | MSSQL `SELECT 1 AS a\nGO 2\nSELECT 2 AS b` | 批次整体重复：结果 1/2 为 `a`，结果 3 为 `b`；`GO` 不进入消息；`GO 0`/超限报错 |
| EDIT-13 | 手工 | 执行中按 F5/取消按钮 | 取消当前查询；按钮/状态恢复；被 KILL 的语句按 canceled 覆盖成功响应 |
| EDIT-14 | 手工 | 超长 SQL（>1MB） | 执行前提示拆分/另存，不直接发送 |
| EDIT-15 | 手工 | 编辑器右键菜单 | 执行/格式化/复制/剪切/粘贴/从历史插入；复制剪切需选区，粘贴需剪贴板有文本 |
| EDIT-16 | 手工 | 从历史插入 | 插入到光标处；弹窗关闭；编辑器可撤销 |
| EDIT-17 | 手工 | 草稿自动保存/恢复 | 30 秒或正常退出后重开恢复标签和 SQL；不自动执行 |
| EDIT-18 | 手工 | 打开/另存为/最近文件/拖入 `.sql` | 文件路径记录；保存覆盖原文件；拖入 `.sql`/`.txt` 打开标签 |
